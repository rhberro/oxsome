# Oxsome playground

This Bun project uses the local Oxsome package. Its React component demonstrates a named callback with an inline `useMemo` dependency array and `Array<number>` in a public prop type.

From the repository root:

```sh
npm run build
cd example
bun install
bun run check
bun run start
```

Edit `index.ts` or `MyComponente.tsx` to try a rule. Run `bun run lint` for lint errors, `bun run format` to format files, and `bun run check` for lint, formatting and type checking together.
